## 🟣 INTERVIEW TALKING POINTS

**Q: Tell me about a data analytics project you've worked on.**

"I built a complete data analytics project on the Zomato Bangalore dataset with over 56,000 restaurant records.
The project had three key phases:

First, **data cleaning** — I created a 9-step pipeline to handle missing values (some columns had 50% nulls), remove duplicates, clean the rating column which had values like '4.1/5' mixed with text like 'NEW', encode binary features, and engineer new columns like price_category and primary_cuisine.

Second, **EDA and analysis** — I produced 14 visualisations covering location distribution, cuisine rankings, cost-rating relationships, and the impact of online ordering and table booking. The most interesting finding was that restaurants offering table booking averaged 0.3 rating points higher — suggesting that operational quality correlates with customer service quality.

Third, **business recommendations** — I translated the data into 6 strategic recommendations including a Bayesian restaurant ranking algorithm and an online-order penetration campaign.

The entire analysis is documented in a Jupyter Notebook with an auto-generated PDF report."
